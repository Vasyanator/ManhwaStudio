# Fixtures: ms-region-postprocess

Golden parity fixtures for the region post-processing port (global colour match, local CIELAB
match, inward feather, composite, cv2 ellipse dilation). Everything except this README is
GENERATED by `tools/make_region_postprocess_fixtures.py` from the reference Python
`modules/ai_backend/inpaint/region_imaging.py` at revision `c11c4eb` (loaded with `git show`, so
it still works after the Python helpers were deleted). Inputs are synthetic; no page content.

Regenerate (byte-deterministic for the numpy / OpenCV / Pillow versions in `manifest.json`):

```bash
venv/bin/python -I tools/make_region_postprocess_fixtures.py
```

## Layout

- `manifest.json`: reference revision + sha256 of the reference source, library versions, case
  list, dilation radii.
- `kernels.json`: `kernels[r-1].half_widths[i]` = half width of row `dy = i - r` of
  `cv2.getStructuringElement(MORPH_ELLIPSE, (2r+1, 2r+1))`, r = 1..=64 (each row is a centred
  contiguous span; checked by the generator). `plan_formula_mismatches` lists rows where
  `round_half_even(r * sqrt((r^2 - dy^2) / r^2))` disagrees; it is empty for OpenCV 4.12.
- `dilation/input.png` (L8 0/255, 97x83, touches all four borders, isolated pixels including two
  corners, a 1 px line) and `dilation/dilate_r{3,6,16}.png`: `cv2.dilate` with that kernel,
  default border (out-of-bounds pixels absent).
- `jitter.json`: `splitmix64` known answers (`key` -> `hash`, u64) and two small
  `row_index` / `col_index` grids of the splitmix jitter rule (`padded_h`, `padded_w`, `level`,
  stride = `2**level`).
- `cases/<name>/`: one case.
  - Inputs: `base.png` (RGB, composite base), `generated.png` (RGB, raw model output),
    `mask.png` (L8 0/255, composite mask), `sample_mask.png` (L8, colour-match mask; equals
    `mask.png` unless `sample_mask_distinct`), `reference.png` (RGB, colour-match reference;
    ONLY when `reference_distinct`, otherwise the reference is `base.png`).
  - `patched/`: `global.png` (after the global match), `local.png` (after the local match),
    `alpha.png` (L8 feather alpha, 0 outside the mask), `expected.png` (final composite).
  - `unpatched/`: `local.png`, `alpha.png`, `expected.png` of the untouched reference. No
    `global.png`: the global stage depends on neither patch and the generator asserts it is
    byte-identical to `patched/global.png`.
  - `case.json`: `width`, `height`, stored `settings` (the persisted `PostprocessSettings` keys),
    `whole_region`, `effective` (`feather_px`, `global_match`, `local_strength_pct` — strength is
    `pct / 100` as f32 — `local_scale_px`), `reference_distinct`, `sample_mask_distinct`,
    `sample_mask_rule`, `mask_pixels`, the branch taken (`global_path`: `margin` | `unmargined` |
    `skipped` | `off`; `local_path`: `applied` | `skipped` | `off`) with the sample counts that
    decide it, `patched_diagnostics` (cv2 helper paths vs the numpy fallbacks the patched set
    runs) and `unpatched_deviation` (unpatched minus patched, per stage: `max_abs`, `p99_abs`,
    `differing_values`).

Stage chaining: `global = match(generated, reference, sample_mask)` when `global_match`, else
`generated`; `local = local_match(reference, global, sample_mask)` when `local_strength_pct > 0`,
else `global`; `expected = composite(base, local, mask, feather_px)`.

## The two sets

`patched/` is the parity target. It is the reference with the port's deliberate deviations:

1. **Exact EDT feather.** The inward distance is `cv2.distanceTransform(DIST_L2,
   DIST_MASK_PRECISE)` (exact Euclidean) on the mask padded by a 1 px zero ring, instead of the
   reference's 5x5 chamfer (`DIST_L2, 5`).
2. **splitmix jitter.** The local match's one-sample-per-block jitter (cascade level `i >= 1`,
   stride `2**i`) uses `key = (level << 48) ^ (block_row << 24) ^ block_col`,
   `h = splitmix64(key)`, `row = min(block_row*stride + (h & 0xFFFFFFFF) % stride, padded_h-1)`,
   `col = min(block_col*stride + (h >> 32) % stride, padded_w-1)` instead of numpy's
   `default_rng(level)`.
3. The local match's `_mix_channels`, `_box_downsample`, `_upsample_linear` and
   `_gaussian_blur` run their numpy FALLBACK paths, the ones the Rust port implements; mask
   dilation stays real cv2.

`unpatched/` is today's real output (chamfer, PCG64 jitter, cv2 helpers), for reporting how far
the port drifts from the shipped behaviour; it is not a parity target.
